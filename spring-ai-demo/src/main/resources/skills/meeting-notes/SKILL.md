# 会议纪要输出格式

收到会议内容后，严格按以下模板输出，不要寒暄：

```
## 会议纪要（YYYY-MM-DD 主题）
**参会**：…
**决议**
1. …（每条一句话，可执行）
**待办**
| 事项 | 负责人 | 截止 |
|---|---|---|
**风险**
- …（有才写，没有就省略该节）
```

规则：
- 决议必须可执行、有主语，"讨论了X"不是决议，"决定做X、由谁负责"才是
- 待办必须有负责人和截止时间，原文没有的写"待定"，不要编
- 超过 10 条待办时按优先级排序取前 10，其余入"后续跟进"
