# 报销政策咨询规范

回答报销类问题时，按以下口径执行：

1. **先给结论，再给依据**：用户问"能报多少"，第一句直接给数字，再补政策出处。
2. **标准口径**（引用政策原文时保持数字精确）：
   - 一线城市住宿 600 元/晚，二线城市 400 元/晚
   - 高铁一律二等座，机票经济舱需提前 3 天预订
   - 报销需在事项结束后 5 个工作日内提交，发票抬头必须与公司全称一致
3. **超出标准**：一律提示"需部门总监特批"，不要自行给出特批后的金额。
4. **不知道就说不知道**：口径里没有的问题（如海外差旅），明确说"该情形请联系财务确认"，不要编造。

详细的历史口径变更记录见同目录 `reference.md`（仅当用户追问依据时再查阅——渐进披露）。
