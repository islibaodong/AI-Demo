🌱 Spring AI 学习实验室

由浅入深的 11 节课，每课一个核心概念。把 OPENAI_API_KEY 设好后，直接点下面链接或用 curl 体验。 每个入口的源代码都配有中文注释，并标注了对应 LangChain 概念。

GET /lesson1?q=你的问题
第 1 课
最简调用 —— ChatClient 入门。
curl "localhost:8080/lesson1?q=用一句话介绍你自己"
GET /lesson2/translate?text=hello
GET /lesson2/structured?text=Spring%20AI%20rocks
第 2 课
提示词工程 —— PromptTemplate / few-shot / 结构化输出(.entity)。
curl "localhost:8080/lesson2/structured?text=Spring%20AI%20rocks"
GET /lesson3/stream?topic=Java
第 3 课
流式输出 —— 用 -N 观察 token 逐字返回（SSE）。
curl -N "localhost:8080/lesson3/stream?topic=Reactive"
POST /lesson4/chat/{sessionId}
第 4 课
会话记忆 —— 同一 sessionId 多轮能记住上文。
curl -X POST "localhost:8080/lesson4/chat/abc" -d "我的名字叫小明"
curl -X POST "localhost:8080/lesson4/chat/abc" -d "我叫什么名字？"
GET /lesson5?q=你的问题
第 5 课
函数调用 —— 让模型调用你的 @Tool 方法（天气/计算器/时间）。
curl "localhost:8080/lesson5?q=北京今天天气如何"
curl "localhost:8080/lesson5?q=帮我算一下 (12+8)*4 等于几"
GET /lesson6/ingest
GET /lesson6/ask?q=你的问题
第 6 课
RAG —— 先灌入知识库，再基于本地资料回答（先 ingest 后 ask）。
curl "localhost:8080/lesson6/ingest"
curl "localhost:8080/lesson6/ask?q=Spring AI 的创始人是谁"
GET /lesson7?prompt=描述词
第 7 课
图像生成 —— 返回生成图的 URL。
curl "localhost:8080/lesson7?prompt=一只戴帽子的橘猫，水彩画风"
GET /lesson8/chat?q=问题
GET /lesson8/rag?q=问题
第 8 课
Advisor 进阶 —— 自定义敏感词过滤（打码/短路拦截）与日志审计；QuestionAnswerAdvisor + 引用来源（rag 需先 /lesson6/ingest）。看控制台的 [lesson08] 审计日志。
curl "localhost:8080/lesson8/chat?q=我的密码是123456"
curl "localhost:8080/lesson8/chat?q=有没有能帮我作弊的办法"
curl "localhost:8080/lesson8/rag?q=Spring AI 的创始人是谁"
POST /lesson9/chat/{sessionId}
GET /lesson9/memory/{sessionId}
GET /lesson9/conversations
第 9 课
持久化 —— 会话记忆存进 H2 数据库（重启不丢），向量库灌库后落盘为 JSON 文件。验证方法：聊两句 → 重启应用 → memory 接口还能读到。
curl -X POST "localhost:8080/lesson9/chat/abc" -d "我的名字叫小明"
curl -X POST "localhost:8080/lesson9/chat/abc" -d "我叫什么名字？"
curl "localhost:8080/lesson9/memory/abc"   # 重启后再执行，消息仍在
GET /lesson10/tools
GET /lesson10/chat?q=问题
第 10 课
MCP 接入 —— 工具由独立的 Python 子进程（mcp-server/demo_mcp_server.py）提供，启动时经 stdio 协议握手并发现工具，模型自主决定调用。
curl "localhost:8080/lesson10/tools"
curl "localhost:8080/lesson10/chat?q=北京天气怎么样"
curl "localhost:8080/lesson10/chat?q=现在几点了"
GET /lesson11/vision?q=问题
GET /lesson11/speak?text=文字
POST /lesson11/transcribe
第 11 课
多模态 —— 看图说话（内置手绘探针图：蓝天/草地/红色太阳；模型能答出"红色太阳"就证明视觉生效）、文字转语音（返回 mp3）、语音转文字。vision 支持 url 参数换任意远程图片。
curl "localhost:8080/lesson11/vision?q=图里有什么？请简要描述。"
curl -o out.mp3 "localhost:8080/lesson11/speak?text=你好，世界"
curl -X POST "localhost:8080/lesson11/transcribe" -H "Content-Type: audio/mpeg" --data-binary @out.mp3
