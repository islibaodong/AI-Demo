🌱 Spring AI 学习实验室

由浅入深的 7 节课，每课一个核心概念。把 OPENAI_API_KEY 设好后，直接点下面链接或用 curl 体验。 每个入口的源代码都配有中文注释，并标注了对应 LangChain 概念。

GET /lesson1?q=你的问题
第 1 课
最简调用 —— ChatClient 入门。
curl "localhost:8080/lesson1?q=用一句话介绍你自己"
GET /lesson2/translate?text=hello
GET /lesson2/structured?text=Spring%20AI%20rocks
第 2 课
提示词工程 —— PromptTemplate / few-shot / 结构化输出(.entity)。
curl "localhost:8080/lesson2/structured?text=Spring%20AI%20rocks"
GET /lesson3/stream?topic=Java
第 3 课
流式输出 —— 用 -N 观察 token 逐字返回（SSE）。
curl -N "localhost:8080/lesson3/stream?topic=Reactive"
POST /lesson4/chat/{sessionId}
第 4 课
会话记忆 —— 同一 sessionId 多轮能记住上文。
curl -X POST "localhost:8080/lesson4/chat/abc" -d "我的名字叫小明"
curl -X POST "localhost:8080/lesson4/chat/abc" -d "我叫什么名字？"
GET /lesson5?q=你的问题
第 5 课
函数调用 —— 让模型调用你的 @Tool 方法（天气/计算器/时间）。
curl "localhost:8080/lesson5?q=北京今天天气如何"
curl "localhost:8080/lesson5?q=帮我算一下 (12+8)*4 等于几"
GET /lesson6/ingest
GET /lesson6/ask?q=你的问题
第 6 课
RAG —— 先灌入知识库，再基于本地资料回答（先 ingest 后 ask）。
curl "localhost:8080/lesson6/ingest"
curl "localhost:8080/lesson6/ask?q=Spring AI 的创始人是谁"
GET /lesson7?prompt=描述词
第 7 课
图像生成 —— 返回生成图的 URL。
curl "localhost:8080/lesson7?prompt=一只戴帽子的橘猫，水彩画风"
